# Happening Now — 事件实时发生判断器

## 概述

一个纯前端 Web 应用，判断用户输入的事件是否"每分每秒"都在全球发生。结合本地数据统计和 LLM 推理，配合 3D 地球动画和实时计数器进行数据可视化展示。

## 技术方案

- **形式**：单文件 `index.html`，内联 CSS + JS，零依赖
- **AI 接口**：OpenAI 兼容格式 API，可配置 endpoint/key/model
- **存储**：API 配置存 localStorage
- **兼容**：现代浏览器（Chrome/Edge/Firefox/Safari 近两年版本）

## 页面布局

### 顶部 — 输入区

- 输入框 + "分析"按钮
- 预设示例快捷按钮：
  - "有人正在喝可口可乐"
  - "有人正在出生"
  - "有人正在发推特"

### 中间 — 结果展示区（分析后出现）

- **左侧**：Canvas 3D 地球动画
  - 事件发生时随机位置冒出光点（偏向人口密集区域）
  - 光点扩散后消散，频率对应 `frequency_per_second`
  - 支持鼠标滚轮缩放、拖拽旋转、双击重置
- **右侧**：
  - 结论标签："是 / 极有可能 / 不太可能 / 否"
  - 频率估算："每秒约 X 次"
  - 推理依据（数据来源 + AI 推理过程）
  - 实时计数器："从你打开页面起，这件事已经发生了约 X 次"（带滚动数字动画）
  - 频率对比图（脉冲动画 + 柱状图对比其他常见事件）

### 底部 — 设置区（可折叠）

- API 地址、API Key、模型名称输入框
- 保存按钮，存入 localStorage

## 核心判断逻辑

### 第一步 — 本地数据层

内置约 30-50 条常见事件频率数据（JSON），通过关键词模糊匹配查询：

| 事件 | 频率 |
|------|------|
| 全球出生 | ~4.3 人/秒 |
| 全球死亡 | ~1.8 人/秒 |
| 可口可乐销量 | ~2 万瓶/秒 |
| 推特发帖 | ~6000 条/秒 |
| Google 搜索 | ~10 万次/秒 |
| ... | ... |

### 第二步 — AI 推理层

将事件描述 + 命中数据（如有）发给 LLM，要求返回结构化 JSON：

```json
{
  "happening": true,
  "confidence": "high",
  "frequency_per_second": 2.5,
  "reasoning": "全球约80亿人口，可口可乐日销20亿份...",
  "data_sources": ["可口可乐2024年报", "全球人口统计数据"]
}
```

### 判断标准

| 频率 (次/秒) | 结论 |
|-------------|------|
| >= 1 | 是，每秒都在发生 |
| 0.1 ~ 1 | 极有可能，约每 N 秒一次 |
| 0.01 ~ 0.1 | 偶尔发生，约每 N 分钟一次 |
| < 0.01 | 不太可能每秒都在发生 |

## 可视化细节

### 地球

- 纯 Canvas 2D 绘制（带经纬线的球体 + 旋转动画）
- `requestAnimationFrame` 驱动
- 光点：随机位置（人口密集区域权重更高），冒出发光 → 扩散 → 消散

### 实时计数器

- 页面打开后持续计时累加
- 数字滚动动画（里程表效果）
- 显示已过时间

### 频率对比

- 脉冲动画：每发生一次闪一下
- 柱状图：与内置数据表中其他事件对比

## 容错

- LLM 返回非 JSON → 尝试提取，失败显示"分析失败，请重试"
- 网络错误 → 显示错误提示
- 请求超时 → 15 秒
- 关键词匹配无结果 → 完全交给 AI

## 国际化 (i18n)

- 支持中文和英文两种语言
- 语言切换按钮在页面右上角
- 语言偏好存 localStorage，下次打开自动应用
- 所有 UI 文本通过翻译字典渲染，不硬编码
- AI Prompt 会根据当前语言调整（中文模式用中文提问，英文模式用英文提问）
- 内置事件数据表同时包含中英文关键词和事件名
- 判断结论文案根据语言显示

## 安全

- API Key 仅存 localStorage
- `<meta>` 禁止 iframe 嵌入
